# ai-marketplace

Richkid's private Claude Code plugin marketplace.

This repo holds **reviewed copies** of third-party plugins and skills — not links to upstream. Upstream changes never reach the team until someone reviews and re-copies them in here.

- `plugins/` — reviewed plugin packages (skills + commands + hooks/scripts as needed)
- `skills/` — reviewed single skills
- `UPSTREAM.md` — tracks what was copied from where, and when

Install for the team:

```
/plugin marketplace add Richkid-ai/ai-marketplace
/plugin install <name>@richkid
```
